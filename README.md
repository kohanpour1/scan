# Scanner – مدیریت انبار با اسکن بارکد

اپلیکیشن اندروید ساده برای ثبت ورود و خروج کالا با اسکن بارکد یا ورود دستی سریال.

## ویژگی‌ها
- اسکن انواع بارکد با دوربین گوشی
- تعریف چند نوع محصول
- ثبت ورود به انبار / خروج از انبار
- حفظ انتخاب محصول و نوع عملیات بعد از هر اسکن
- صدای متفاوت برای ورود، خروج و خطا (دو بوق)
- خروجی Excel و PDF شامل خلاصه موجودی و خلاصه خروجی
- ذخیره فقط روی خود گوشی

## بیلد
با push به شاخه `main` یا اجرای دستی workflow «Build Android APK» فایل APK در Artifacts قرار می‌گیرد.
